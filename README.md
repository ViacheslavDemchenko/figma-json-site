# figma-json-site

Заготовка проекта для верстки сайта по экспортному Figma JSON.

## Структура

- `index.html` — базовая структура страницы
- `css/style.css` — базовые стили
- `js/main.js` — мобильное меню и заглушка формы
- `assets/` — папка для изображений
- `figma-file.json` — экспорт макета из Figma

## Следующий шаг

Открой проект в VS Code и передай Codex задачу:

Проанализируй `figma-file.json`. Найди `Frame 1` и `Frame 95`. Сначала дай отчет по секциям, цветам, шрифтам, размерам, изображениям и плану верстки. Пока ничего не меняй.
